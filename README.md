AI SECURITIES is a beginner-level network security project that controls access to a server using IP addresses. In Cisco Packet Tracer, a client–router–server network is built where a standard ACL on the router allows the authorised PC-A (192.168.10.10) and blocks the unauthorised PC-B (192.168.10.20). On a real computer, XAMPP hosts an Apache test website with an IP-based rule, returning HTTP 200 OK to the authorised address and 403 Forbidden to others. Wireshark captures both requests, while router ACL counters and Apache logs record every allowed and blocked attempt. The project combines IP addressing, access control, web-server operation and traffic monitoring in one safe lab.
